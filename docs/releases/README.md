# Stellons Release History

## Overview

Stellons began as an AI orchestration and planning platform.

The original system focused on converting natural language goals into structured task plans through agent workflows.

During the v0.4.x release cycle, Stellons evolved into an AI Infrastructure Generation Platform capable of producing Terraform projects directly from natural language prompts.

## Key Achievement

The most significant accomplishment of the v0.4.x cycle was the transformation of Stellons from a planning assistant into an AI Infrastructure Generation Platform.

Stellons can now accept a natural language infrastructure request and produce validated Terraform project artifacts ready for deployment workflows.
