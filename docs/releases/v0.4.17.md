# Stellons v0.4.17

## Release Name

Export Metadata

---

## Objective

Add operational metadata to Terraform exports.

---

## Architecture Before

Terraform Export
↓
Artifacts

---

## Architecture After

Terraform Export
↓
Artifacts
↓
Metadata

---

## Technical Changes

Added:

- generated_at
- cloud
- resource_type
- api_version

---

## Problems Encountered

Exports lacked context.

Users could not determine:

- generation time
- infrastructure type
- API version

---

## Resolution

Introduced export metadata model.

Enhanced API response.

---

## Example

{
    "generated_at": "2026-06-17T13:19:35",
    "cloud": "azure",
    "resource_type": "aks",
    "api_version": "0.4.17"
}

---

## Lessons Learned

Artifacts require metadata for traceability.

---

## Impact

Created audit-friendly Terraform exports.
